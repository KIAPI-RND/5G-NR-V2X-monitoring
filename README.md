# 5G-NR-V2X-monitoring

[5G-NR-V2X-monitoring] 
 1. KIAPI OBU/RSU 실시간 상태 모니터링을 위한 웹페이지 구현 코드
    -


  - 본 프로그램은 5G-NR-V2X 통신을 이용하는 장치의 모니터링을 위한 웹페이지 구현
  - 백앤드 장치 DB 연동 및 실시간 데이터 수집
  - 지도와 연동하여 정밀맵 및 장치 표출

2. 프로그램 활용 시 참고사항
   -

- 해당 프로그램 코드의 경우, 5G-NR-V2X 장비의 실시간 모니터링을 위한 백앤드/프론트앤드 코드 일부를 포함
- DB 데이터를 실시간으로 수집하고 패치하는 코드를 일부 포함
- 실제 5G-NR-V2X 장치의 정보를 저장하는 데이터베이스의 설계 구조 및 쿼리는 포함하고 있지 않습니다.
